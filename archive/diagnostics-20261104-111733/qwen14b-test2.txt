```powershell
function Test-PortProcess {
    [CmdletBinding()]
    param (
        [Parameter(Mandatory = $true)]
        [int[]]$Ports
    )

    foreach ($port in $Ports) {
        try {
            $connection = Get-NetTCPConnection -LocalPort $port -State Listen -ErrorAction Stop
            if ($connection) {
                $processId = $connection.OwningProcess
                try {
                    $processName = (Get-Process -Id $processId -ErrorAction Stop).Name
                }
                catch {
                    $processName = "N/A (权限不足或系统进程)"
                }
            }
            else {
                $processName = "Not Listening"
            }
        }
        catch {
            $processName = "Error: $_"
        }

        [PSCustomObject]@{
            Port        = $port
            Status      = if ($connection) { "Listening" } else { "Not Listening" }
            ProcessName = $processName
        }
    }
}
```

### 功能说明：
1. **参数兼容性**：接受整数数组参数 `$Ports`，支持多个端口同时检测
2. **跨版本兼容**：
   - 使用 PowerShell 5.1/7 共有的 `Get-NetTCPConnection` 命令
   - 使用 `-ErrorAction Stop` 统一异常处理
3. **进程信息获取**：
   - 通过 `OwningProcess` 获取监听进程ID
   - 使用 `Get-Process` 获取进程名，捕获权限不足或系统进程异常
4. **返回结果**：
   - 每个端口返回自定义对象，包含：
     - `Port`：检测的端口号
     - `Status`：监听状态（Listening/Not Listening）
     - `ProcessName`：监听进程名或错误信息

### 使用示例：
```powershell
Test-PortProcess -Ports 80, 443, 3389
```
