1. 渠道刚起步：抖音仅 2 条成品，1 条 11-14 已发、1 条 11-16 审核中（`marketing/douyin/连载规划.md`），审核中无公开地址。

3. 发版时间短：v0.12.0 为 11-15，截至取证约 4 天；63 次提交集中在开发期内部推进，未见面向社区的分发动作留档。

### (b) 定位问题（有人看但不觉得有用）——待验证假设，置信约 25%

README 首屏卖点堆叠（进程调度、自然语言控制、MCP、安全扫描、模型路由、规则引擎），普通用户 5 秒内可能抓不住"解决我什么问题"。**但无访问量、停留时长、点击-下载漏斗数据，无法判断看过的人是否离开。** 这是假设，不是结论。

### (c) 产品问题（装了不用/不好用）——待验证假设，置信约 15%

本机日志存在多类 WARN/ERROR（底账 §3：EcoQoS PID 竞态 5 次、I/O 优先级权限不足、电源计划枚举为空、action 解析失败、总线认证失败）。若出现在外部干净系统上可能直接劝退；但样本全部来自作者本机，外部影响面未知（底账 §7.6）。

## ⑤ 版本号混乱的市场代价

### 事实（底账 §2.3，实测）

三套版本号并存：对外安装包与 Release tag = **v0.12.0**；内核 = **v0.13**；应用 `APP_VERSION` = **1.00**；`/api/health` 返回 `version=1.00, kernel_version=v0.13`；`current.json` 指向 v0.13。

### 市场侧代价（假设处明确标注）

1. **用户观感**：技术用户下载 0.12.0 包，打开看到 1.00 / v0.13，会怀疑"下错包了？测试版？"。1.00 暗示正式版成熟度，0.12.0 暗示公测早期，两个相反信号同时出现。（基于版本语义的**假设**，无访谈数据。）
2. **发布成本**：每篇对外内容都要先解释"应用/内核/Release 三条线"，解释成本推给读者。
3. **物料口径已漂移（实测）**：投稿简介 `submission-copy.md` 仍写"v0.11.1""104 项 pytest"；抖音 v0.12.0 文案写"v0.12.0、113 个测试全过"。CHANGELOG 实测 v0.11.1=104、v0.12.0=113（L96/L162），旧物料未随发版更新。
4. **信任损耗**：对技术受众，版本号不收敛是"工程未收敛"的可见信号；普通用户感知弱，但在"关于/版本"页会困惑。**同类公开案例本轮未检索到一手来源，按假设登记，不编造案例。**

- 失败：7 天仍 0 外部反馈 → 暂停新视频生产，转小范围灰度/访谈，不自嗨更新。

## ⑧ 热感知调度市场判断 + 更可信卖点

### 对外讲得通吗？——当前讲不通，且有被打脸风险

1. **感知错位**：普通用户不关心"温度"工程指标，关心"卡不卡、风扇吵不吵、会不会降频"；"热感知调度"是工程语言。
2. **口径未裁定**：底账 §1 温度冲突——董事长口径核心 94–95℃，实测 ACPI 热区 73.1/72.1℃、GPU 54℃；采样点/时点未对齐，待数据分析师与 DevOps 复核。结论出来前不讲温度卖点。
3. **能力未闭环**：现有温度链路以只读展示与落盘为主，按温度主动调度无可演示闭环。

### 更可信的对外卖点（3 条，附依据）

1. **"给正在跑的模型/游戏让路，松开手完整还原，不杀进程"**——依据：README 核心特性、v0.12.0 Release 说明；本机释放路径可正常工作（底账 §3 行 58/106/134）。用户可直接感知"我开着的东西没被关掉"，是当前最具体可演示的价值点。
2. **"只监听本机回环，令牌鉴权 + 白名单动作，数据不外传"**——依据：README 安全模型、`server.py` 路由与双令牌设计（底账 §2.2）。对在意隐私的本地模型玩家是强卖点，且可被自行验证。
3. **"说人话也能操作，敏感指令不经过 LLM"**——依据：README 自然语言控制特性。置信中等：使用频次无数据，需外部试用验证后再放大。

温度能力保留为只读展示与落盘证据，作第二条视频素材，不作主卖点；口径校准、闭环可演示后再提。

## ⑨ 对外内容 5 条禁语

1. **"提升 XX% 性能 / 加速 XX% / 帧数涨 XX"**——无受控对照实验与 benchmark 数据，禁止任何量化性能承诺。
2. **"杀毒 / 保电脑安全 / 替代专业安全软件"**——README 免责声明明确扫描结果仅供参考、不替代专业安全软件；禁止安全承诺。
3. **"1.0 正式版 / 稳定版 / 量产版"**——对外 tag 仍在 0.12.0 公测线，1.00 是内部应用版本号；禁止把内部号当成熟度信号。
4. **"全网最快 / 唯一 / 第一 / 最强"**——无竞品横评实测支撑，绝对化表述既无证据也有广告法风险。
5. **"过热自动保护 / 温控降频调度"**——热感知未闭环、温度口径未裁定（底账 §1 D3）；禁止暗示已有主动温控能力。

补充红线：不得宣称"支持远程控制 / 任意云端模型接入"——服务仅绑定 127.0.0.1，云端路由依赖用户自配且未配置即 503。
