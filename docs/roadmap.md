## 1. 定位（不变的主线）

PowerFocus 是一台跑在用户本机的 **Windows 算力调度台**：把有限的 CPU、内存、显存优先让给
正在使用的应用和本地模型，把任务管理器、调度台、对话控制收进同一个窗口，并提供标准 MCP 接口
供 AI 客户端调用。

- **优先服务本地模型**：总览第一屏展示已载入模型、显存占用与内核在线状态；没有本地模型时，
  它仍是一台通用调度台。
- **本机回环、默认不上传**：服务绑定 `127.0.0.1`，接口需本机令牌；运行态数据只写
  `%LOCALAPPDATA%\PowerFocus`。使用云端模型对话时，输入内容由用户自己配置的第三方服务商
  按其隐私政策处理，本项目不经手、不存储、不转发。
- **非商业化**：个人开发者维护的开源项目（Apache-2.0），不做云控、不做远程后台、不预置第三方二进制。

## 3. Next · 下一阶段（已评估，未动工）

### 3.1 系统托盘（本轮已降级，原因如实记录）

- **评估结论**：pywebview 6.2.1 提供 `events.closing`（回调返回 `False` 可取消关闭）与
  `window.hide()/show()`，但**没有原生托盘图标 API**；NotifyIcon 需经 pythonnet 双 WinForms
  消息循环，无人值守长期运行的稳定性在本机未经验证。
- **本轮处理**：`close_action` 枚举保留 `tray`；前端下拉中「最小化到托盘」一项 `disabled`
  并标注「下一版接入」；本轮实际关闭行为只落地 `exit`。
- **下一步前置条件**：先在隔离环境验证 pythonnet 消息循环与 WebView2 共存的稳定性（内存、
  句柄、退出路径），跑通无人值守长稳测试后再接入；不引入未验证的线程模型。

### 3.2 易用性收拢（B 线）

- 简单模式：把专业术语换成用户能直接理解的人话，关键操作少跳转。
- 术语表与默认提示对齐首次引导的四步口径。
- 真人可用性实测：找 2–3 名不了解项目的用户按任务卡操作，记录卡点（台账 #10）。

### 3.3 既有能力补齐

- **每日自动扫描调度器**：`run_scheduled_loop()` 已实现，但尚未随主进程常驻启动；需补启动/
  退出路径与可配置开关。
- **server.py 模块拆分**：抽 `processes.py` / `nlp.py` / `llm_proxy.py`，目标单文件 900 行内
  （工程审计第二批剩余项）。
- **质量门禁**：覆盖率门槛（≥60% 起步）、路由集成测试、exe 冒烟（启动 → `/api/health` → 关闭）。

## 4. Later · 排期待定（需产品授权或前置决策）

以下来自双专家审查与供应链审计的开放项，**本轮不假装完成**，逐项见 `engineering-audit.md`
与 `CHANGELOG.md` 的「未修安全项」：

- **F4 命令总线认证**：内核命令总线本身无认证，能写 `commands/in` 的本地进程可驱动内核；
  改动约 2000 行 PowerShell 内核且涉及 stable 指针，需单独排期。
- **F7 验签 TOCTOU**：KVRT 验签与执行之间应重验并重算 SHA256。
- **F8 同意令牌**：`dependency_bootstrap.py` 的同意令牌为源码可读硬编码常量，需改非对称或短时令牌。
- **F3**：`/api/health` 当前在限流豁免集合内，需评估是否纳入限流。
- **KVRT 下载源锁定**：现为 `latest` 直链，未锁定具体版本；应锁版本 + SHA256。
- **CI 供应链与发行**：commit SHA pin、`pip-audit` 门禁、tag 触发构建、provenance、
  exe 签名与 SBOM、自托管 runner；需先决定构建与签名策略。

## 5. 指标与边界

- **不承诺未实测的性能数字**：任何「提速 X%」「内存回收 Y MB」类对外表述，必须有本机可复现
  的采样记录支撑；演示页与宣传材料只引用已核实结论。
- **隐私口径（固定）**：旁观者只能看到在用浏览器与访问的域名，看不到打开了哪一页、看了什么；
  不承诺「匿名上网」「加密隐匿」类未兑现能力。
- **安全扫描结果仅供参考**：不替代专业安全软件的实时防护；破坏性操作前需用户确认，重要工作随时保存。

## 6. 明确不做（否决项，勿重复立项）

- 不做藏 IP / VPN / 多重加密隐匿类功能（口径已两次否决）。
- 不把 KVRT、Node.js 等第三方二进制打入仓库或安装包；缺组件先列给用户，同意后从官方源下载验签。
- 不做静默安装、不做未经用户同意的后台常驻；不自建远程控制或云控后台。
- 不把模型对话内容经手、存储或转发到本项目自有服务器。

## 7. 版本与变更记录

- 对外版本号以 GitHub Release tag 为准（SemVer）；`product/v1.00` 是代码目录与数据槽，
  `versions/current.json` 指向内核版本，三者不是一回事。规则详见 `VERSION_POLICY.md`。
- 每轮实际变更追加到 `CHANGELOG.md` 的 `[Unreleased]` 段；逐轮开发细节见 `DEVELOPMENT_LOG.md`。
