> 面向使用者；开发者与构建细节见 [README](../README.md)。遇到问题时先查文末[故障排查](#故障排查)。

## 这是什么

「电脑算力调度中心」是一个 Windows 桌面工具，把这台电脑上的 **CPU、内存、本地大模型、安全扫描**当成同一个资源池来管理：

- **看**：实时资源占用、进程排行、当前调度状态（总览页第一行直接告诉你「现在需要做什么吗」）；
- **调**：对指定进程聚焦（提升优先级）、回收内存、冻结/恢复、终止；一键套用电源与优先级「场景」；
- **跑模型**：启动/停止本地大模型路由，给指定模型出「加速方案」（试算或实际调参）；接云端模型对话；
- **查安全**：对自身防护做真实攻防自检；经你同意后从卡巴斯基官方下载 KVRT 扫描工具做真实病毒扫描；
- **自然语言**：在总览页输入「给我申请一点算力」「清理一下内存」这类指令，应用解析后执行。

**它不是杀毒软件**：扫描结果是检测参考，不替代专业安全软件的实时防护。

## 安装与启动

### 系统要求
- Windows 10 / 11（64 位）
- WebView2 Runtime（Windows 11 自带；Windows 10 若缺失，安装程序通常会带）

### 方式一：exe（推荐）
1. 从 GitHub Releases 下载 `电脑算力调度中心.exe`（或 `install.ps1` 安装版）；
2. 双击运行。应用只监听本机回环地址（127.0.0.1），接口需本机令牌——**不对外提供网络服务**；
3. 手滑多双击几次也不会开出第二个实例（单实例锁）。

### 方式二：从源码运行
```powershell
git clone <仓库地址>
cd PowerFocus
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt   # 若无 requirements 就按报错装
.venv\Scripts\python product\v1.00\app\main.py
```

### 数据放在哪
所有运行数据（扫描报告、组件引擎、日志、配置）都在
`%LOCALAPPDATA%\PowerFocus\<版本槽>`，**不写程序目录、不上传**。
卸载时是否删除这些数据由你决定（见文末卸载一节）。

## 界面速览

左侧导航分两组；顶栏右侧三个圆点是心跳灯（绿=正常呼吸，红=断了）。

| 视图 | 干什么 | 快捷键 |
|---|---|---|
| 总览 | 状态判定 + 资源 KPI + 进程 TOP8 + 自然语言指令 | `1` |
| 进程 | 全量进程表：搜索、排序、选择后执行操作 | `2` |
| 场景 | 一键套用电源/优先级预设组合 | `3` |
| 模型与对话 | 本地模型路由 + 云端/本地对话 | `4` |
| 安全态势 | 防护攻防自检 + 事件审计 | `5` |
| 组件自检 | 检查 7 类组件、按需补齐 | `6` |
| 设置 | 云端模型凭据（加密落盘） | `7` |
| 日志 | 运行事件流水 | `8` |
| 折叠侧栏 | 图标模式，状态记忆 | `[` |

> 出问题时**先看总览第一行**：绿色「一切正常」就什么都不用做；
> 黄/红时会写明问题和建议动作——界面只在有事时向你开口。

## 常见任务

### 1. 第一次使用：配云端模型（可选）
`设置` → 填 API 地址、模型名、API Key → 「保存」→「测试连接」。
密钥经 Windows DPAPI 加密后落盘，只在本机可解。清除密钥用「清除密钥」按钮。
不配云端也能用：进程调度、场景、本地模型、自检一样不落，全都不依赖云端。

### 2. 查谁在吃资源并处理
`进程` → 搜索框输入名字或 PID → 点行选中 → 底部操作条：
- **聚焦·高/中/低**：提升该进程优先级（对系统关键进程，内核会拒绝并给出原因）；
- **回收内存**：修剪该进程工作集；
- **冻结 / 恢复**：挂起与继续（别冻结你正在用的应用）；
- **终止进程**：强杀（红色按钮，二次确认）。
选错就点「解除聚焦」恢复。

### 3. 一键切场景
`场景` → 点卡片 → 确认。场景会改电源方案、批量调优先级、清后台。
右上角 **?** 有说明。执行前都有二次确认。

### 4. 启动本地模型 / 出加速方案
`模型与对话` → 左侧下拉选模型 → 「启动」（会占显存/内存，会二次确认）→ 用完「停止」。
「加速方案」默认**试算**（只出方案不动手）；确认没问题再切「执行」。

### 5. 做一次真实病毒扫描
`组件自检` → 找到「KVRT 引擎」→ 若缺失，点「同意并补齐缺失组件」→
应用从**卡巴斯基官方源**下载（约 120 MB）并做 Authenticode 签名验证 →
然后在扫描入口发起扫描。报告留在应用内，可随时回看。

### 6. 安装卡巴斯基完整版（可选，系统级）
`组件自检` → 卡巴斯基完整版未安装时，「同意并补齐」只会**下载并验签官方安装器**，
**不会自动安装**。点「启动官方安装向导」→ 红色二次确认 → 由**你本人**在厂商向导里
完成安装（需要管理员、可能要求重启）。应用不代你接受任何协议。

### 7. 验证防护有没有用
`安全态势` → 「立即自检」：应用会发起真实攻击请求并验证全部被拦截
（PASS/FAIL 徽章逐条显示）。说白了，这是对着自己打的一场真实攻防。

### 8. 用自然语言下指令
`总览` 底部指令栏试试：
- 「给我申请一点算力」
- 「清理一下内存」
- 「解除聚焦」
解析结果先展示，执行前按危险程度确认。

## 故障排查

| 现象 | 原因与处理 |
|---|---|
| 提示「已有实例在运行」 | 已有实例持单实例锁。找托盘/任务栏的既有窗口；顽固残留用任务管理器结束进程后重开 |
| 端口 18080 被占用 | 设环境变量 `POWERFOCUS_APP_PORT` 换端口再启动 |
| exe 被 SmartScreen 拦 | 未签名应用的正常提示：点「更多信息 → 仍要运行」；只从官方 Releases 下载 |
| KVRT 下载失败 | 检查网络后重试；离线环境可手动把官方 KVRT 包放入数据目录 `engines/_offline/` 再走自检 |
| 云端对话报错 | `设置`→「测试连接」看具体错误；检查 API 地址/模型名/密钥与余额 |
| 自检模块显示不可用 | 应用其余功能不受影响（设计如此）；把日志页内容贴到 issue 里 |
| 想彻底重来 | 关应用后删除 `%LOCALAPPDATA%\PowerFocus`（会连引擎与历史报告一起删，想清楚再删） |

## 卸载

- **安装版**：「设置 → 应用」里卸载，或运行安装目录的 `uninstall.ps1`；
- **绿色版**：直接删 exe；
- 数据目录 `%LOCALAPPDATA%\PowerFocus` 默认保留；卸载脚本会**明确询问**是否连数据一起删。

## 隐私与安全

- 全部数据本地存储，应用不内嵌任何遥测；
- 服务仅监听 127.0.0.1，接口需令牌，并校验 Host；
- 云端对话内容由你配置的第三方模型服务商处理（本项目不经手）——详见[免责声明](../README.md#免责声明)
  与[法律合规自查](legal-review.md)；
- 本工具仅限用于你拥有合法权限的计算机。
