## 二、转版前的代码修正（v0.11 内）

### ① 撤销错误的 20% 阈值（本轮最重要）

**原规则**（已删）：
```powershell
$minLayerRatio = 0.20
if ($maxGpuLayers -gt 0 -and $gpuRatio -lt $minLayerRatio) { $maxGpuLayers = 0 }
```

**实测证明反了**（`docs\整机实测-2026-11-15.md`）：

| ngl | GPU 占比 | tg64 (tok/s) |
|---|---|---|
| 0 | 0% | 2.478 |
| 8 | 12.3% | 2.792（+12.7%） |
| 14 | 21.5% | 3.164（+27.7%） |
| 20 | 30.8% | 3.493（+41.0%） |

**现规则**：能上几层上几层，只保留软警告（`< 4 层` 时提示"长上下文会掉速"；`0 层` 时提示"可用显存装不下一层"）。

### ② 白名单补给放行

**原代码**（L153 / L431）：`llama-server` 在白名单里 → `request_power` 拒绝对它补给。

**修复**：
```powershell
$script:Whitelist       = @(..., 'llama-server')   # 不许压/不许杀
$script:SupplyableNames = @('llama-server','python','pwsh','powershell','DoubaoWork')  # 但可以补给
if ($tp.Name -in $script:Whitelist -and $tp.Name -notin $script:SupplyableNames) { 拒绝 }
```
**已验证**：`OK: 算力已补给 llama-server (PID 58292) level=aggressive`。

### ③ KV 预留比例化（上一轮已做）

`ComputeReserveMB = 1024` 固定值 → `ComputeReservePct = 15`（按空闲显存动态推导，256MB 下限）。
`CudaReservedMB = 512` 保持绝对量（NVIDIA 官方：CUDA 上下文约 300MB，不随显存缩放）。

### ④ llama 端口可配（上一轮已做）

四处 `8080` → `$script:LlamaPort`（`POWERFOCUS_LLAMA_PORT` 环境变量可覆盖）。

### ⑤ Python 组件硬编码清干净

v0.11 四个 Python 文件里 12 处 `V0.10` 全部清掉：

| 文件 | 位置 | 改动 |
|---|---|---|
| `dependency_bootstrap.py` | L3 标题 / L652+L809 User-Agent / L1156 description | `V0.10` → 去掉 / `PowerFocus-V0.10/1.0` → `PowerFocus/1.0` |
| `engine_adapters.py` | L3 标题 / L7 路线描述 / L862 description | 同上 |
| `kvrt_bundle.py` | L3 标题 / L99 注释 / L149 User-Agent / L785 description | 同上 |
| `security_scan.py` | L3 标题（"最基础原型"）/ L404 NotImplementedError 文案 / L412 description | 去掉版本号与"原型"字样 |

**语法检查**：`py_compile` 四个文件全通过（exit=0）。

### ⑥ `server.py` 组件目录动态解析（上一轮已做）

`_py_component_dir(name)`：`KERNEL_DIR` 优先 → 扫 `versions/` 取含该组件的最高版本 → 兜底 `v0.10`。
`_bootstrap()` / `_kvrt()` 都用它。

### ⑦ `resolve_kernel()` 不静默兜底（上一轮已做）

无 stable 时取最高版本 + `stderr` 显式告警，不再悄悄回落到 `v0.07`。
