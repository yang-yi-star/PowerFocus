Windows 本地算力调度 · 开源项目

PowerFocus
电脑算力调度中心

把有限的 CPU、内存和显存，优先让给正在使用的应用和本地模型； 任务管理器、调度台与对话控制收进同一个窗口，说人话也能操作。

Apache-2.0 开源Windows 10 / 11 本地回环 · 令牌鉴权标准 MCP 接口
github.com/yang-yi-star/PowerFocus
为什么做它

一台机器上挤着大模型、游戏和剪辑，瓶颈往往不是硬件不够

没人替你做取舍

Windows 自带调度只看进程自身需求，不会知道「现在该让 llama-server 先歇一会」。

市面工具分得很碎

任务管理器只管看，游戏加速器只管游戏，内存清理只管内存，入口散在好几个软件里。

本地模型缺一个调度台

跑本地推理时，显存与内存状态需要一眼看到；关键操作要有确认、可还原、留审计。

本页为问题背景，不代表任何已实测的提速比例；性能结论以本机可复现的采样记录为准。

产品方案

一个面板、一个入口，把调度动作收齐

  • 进程调度 聚焦三档、优先级调整、内存回收、冻结恢复、终止（二次确认）
  • 授权白名单 首次调度某应用前需加入清单，清单外目标一律拒绝
  • 自然语言控制 中文指令离线规则解析优先，LLM 兜底；敏感命令永远不经 LLM 生成
  • 场景模式与规则引擎 游戏 / 工作 / 全力等预设一键切换，规则驱动自动调度
  • 模型路由 本地推理服务与云端 API 双通道，凭据经 DPAPI 加密存储
  • 本地模型优先展示 总览第一屏摆出已载入模型、显存占用与内核在线状态
  • MCP 标准接口 这套能力可以被 AI 客户端直接调用
  • 可还原与审计 每项改动先记原值、可还原，并写入审计日志

核心特性

能力矩阵

01进程调度

聚焦三档（温和 / 强制 / 极限）、优先级、内存回收、冻结恢复、终止二次确认。

02授权白名单

写操作全部走内核白名单动作，后端不允许任意命令透传；不操作受保护的系统进程。

03模型与对话

本地推理与云端 API 双通道；凭据 DPAPI 加密；本地模型状态进入总览第一屏。

04安全态势（可选）

只读体检本机暴露面，按需一键收紧；扫描引擎经用户同意后从官方源下载、验签后运行。

安全扫描为可选能力，结果仅供参考，不替代专业安全软件的实时防护。

安全模型 · 隐私边界

本机优先，边界说清楚

  • 只监听回环地址 服务绑定 127.0.0.1，不开放局域网，无远程控制
  • 令牌鉴权 接口需本机令牌，破坏性操作二次确认
  • 白名单动作 写操作走内核白名单，不透传任意命令
  • 数据落本机 运行态数据只写 %LOCALAPPDATA%\PowerFocus，不写系统目录
  • 第三方组件同意后获取 缺什么先列给用户，同意后从官方源下载验签，不预置、不静默安装
  • 旁观者可见范围 只能看到在用浏览器与访问域名，看不到打开了哪一页、看了什么
  • 云端对话内容 由用户自己配置的第三方服务商按其隐私政策处理，本项目不经手、不存储、不转发
  • 本地快照 进程与资源数据仅存本机，不上传
